# vinyl-dj

My vinyl DJ helper: track lengths, BPM, Camelot keys and cue points for my Discogs collection, plus a playlist builder.

- `records.txt` – which records to include (Discogs release IDs). Put `ALL` on its own line for the whole collection.
- `data/collection.json` – updated every night automatically. Don't edit by hand.
- `data/edits.json` – my own corrections (BPM, key, cues). The nightly update never touches this.
- `*` = unsure / estimated.

BPM and key data by [GetSongBPM.com](https://getsongbpm.com). Collection data from [Discogs](https://www.discogs.com/user/abrimmer/collection).
